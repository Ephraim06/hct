# User preferences

- Do not create Git commits, push to GitHub, or trigger GitHub publishing unless the user explicitly instructs you to do so. Requests to implement or fix features do not imply permission to commit or publish.
- Keep changes local for review by default. Previous permission to commit or publish does not carry over to a new task.

- All in-page controls, dropdowns, calendars, dialogs, validation messages and feedback must use the site’s styling. Do not use browser alert/confirm/prompt dialogs or default validation bubbles. Launch unavoidable operating-system file pickers and browser installation/permission prompts only from styled app controls.
